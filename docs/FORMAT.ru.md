# Формат Prism Mod Folders

Статус: черновик версии 1.

## Назначение

Файл `modfolders.json` описывает виртуальные папки в списке модов Prism
Launcher. Он не перемещает `.jar` по реальным подкаталогам. Все моды продолжают
лежать непосредственно в каталоге `mods`, поэтому формат не влияет на работу
Fabric, Forge, NeoForge или Quilt.

Предлагаемый путь:

```text
<папка Minecraft>/modfolders.json
```

Сам функционал папок создаёт и изменяет только `modfolders.json`. Пользователь
сам выбирает этот файл в штатном окне экспорта Prism; код папок не вмешивается
в упаковку, импорт или другие файлы сборки. Никакие дополнительные постоянные
файлы для папок не создаются.

Обычный Prism Launcher и другие лаунчеры могут безопасно проигнорировать этот
файл.

Файл записывается как форматированный UTF-8 с меткой кодировки, поэтому русские
имена папок нормально отображаются в стандартных редакторах Windows. JSON можно
редактировать вручную: после сохранения достаточно заново открыть страницу
модов.

## Минимальный пример

```json
{
  "formatVersion": 1,
  "folders": [
    {
      "name": "Оптимизация",
      "mods": [
        "sodium-fabric-0.6.13+mc1.21.5.jar",
        "lithium-fabric-mc1.21.5-0.16.2.jar"
      ]
    }
  ]
}
```

## Корневые поля

- `formatVersion` — версия формата. Для первого выпуска всегда `1`.
- `folders` — папки в порядке отображения сверху вниз.

## Папка

- `name` — отображаемое имя, которое вводит пользователь.
- `mods` — имена файлов модов в порядке отображения внутри папки.

Пустые папки разрешены и сохраняются.

Имена папок в пределах одной сборки должны быть уникальными. При
переименовании папки меняется только `name`.

## Ссылка на мод

Каждый элемент `mods` — простая строка с техническим именем файла, которое уже
известно модели модов Prism Launcher:

```json
"sodium-fabric-0.6.13+mc1.21.5.jar"
```

Для отключённого мода также сохраняется имя, заканчивающееся на `.jar`.
Служебный суффикс `.disabled` в JSON не добавляется и при сопоставлении
игнорируется. Поэтому включение и отключение мода галочкой не меняет его папку.

Формат не дублирует отображаемое название, ID мода, хеш или сведения Modrinth
и CurseForge. Для показа названия, версии и иконки интерфейс использует
существующий `ModFolderModel`. Отдельно сканировать или разбирать каталог
`mods` ради группировки не нужно.

Когда Prism Launcher обновляет мод и меняет имя файла, операция обновления
заменяет старое имя новым в `modfolders.json`. Если пользователь заменил или
переименовал файл вручную вне Prism, новый файл появится в секции «Без папки».
Неизвестная старая ссылка сохраняется: это позволяет восстановить группировку,
если файл временно отсутствовал или был добавлен позже при распаковке сборки.

## Правила интерфейса

- Один мод может находиться максимум в одной пользовательской папке.
- Моды, которых нет в JSON, отображаются свободно в корне списка, без папки.
- Перетаскивание меняет только JSON, а не положение `.jar` на диске.
- Удаление папки не удаляет моды: они становятся свободными в корне списка.
- Удаление строки мода внутри папки удаляет только сам мод. Удаление виртуальной
  папки выполняется только при выборе строки-заголовка этой папки.
- Команда переименования доступна при выборе заголовка папки или любого мода внутри
  неё. При выборе свободного мода или элементов из разных папок команда недоступна.
- Пустая папка показывает обычную иконку папки. Непустая папка показывает
  сетку до четырёх иконок модов. Моды для превью всегда выбираются по названию
  в алфавитном порядке, поэтому текущая сортировка таблицы не меняет превью.
- Перенос принимается по всей области строки папки, а штатная линия вставки Qt
  остаётся видимой для точного указания цели.
- Пока пользователь держит мод во время переноса, список продолжает
  прокручиваться колёсиком мыши.
- Значок раскрытия должен быть обычным шевроном: вправо для закрытой папки и
  вниз для открытой.
- Порядок элементов массива `folders` задаёт порядок папок, а порядок `mods` —
  исходный ручной порядок модов внутри папки.
- Сортировка по столбцам Prism применяется отдельно внутри каждой папки и
  отдельно к свободным модам в корне. Например, сортировка по столбцу «Включён»
  перемещает отключённые моды в начало или конец каждой папки, но не переносит
  их между папками.
- Сортировка по столбцам не меняет порядок самих папок и не перезаписывает
  массивы в JSON. После сброса сортировки используется порядок из файла.
- Состояние «открыта/закрыта» не записывается в JSON. Оно хранится только в
  памяти открытого окна редактора сборки и полностью сбрасывается после его
  закрытия.
- После каждой папки отображается отдельный невыбираемый разделитель высотой
  10 пикселей. Линия находится по центру, имеет скруглённые концы и горизонтальный
  отступ; выделение папки или последнего мода на разделитель не распространяется.
- Выделение или открытие мода, в том числе свободного мода без папки, не
  меняет состояния папок. Папка раскрывается и закрывается только явным
  двойным нажатием на её строку либо нажатием на шеврон.

## Надёжность

- При обнаружении одного мода в нескольких папках используется первое
  вхождение; последующие дубликаты при загрузке игнорируются.
- Неизвестные или временно отсутствующие имена не должны приводить к потере
  всего файла.
- Сохранение должно быть атомарным: сначала временный файл, затем замена
  оригинала.
- Некорректный JSON не должен мешать запуску Minecraft. Лаунчер показывает
  ошибку и временно использует обычный плоский список.
