# Патчер Prism Mod Folders

Однофайловый патчер добавляет виртуальные папки модов в существующую
пользовательскую установку Prism Launcher для Windows.

Готовый файл:

```text
dist/PrismModFoldersPatcher-11.0.3.exe
```

Размер текущей сборки — около 1,55 МБ. Внутри находится сжатая бинарная разница
размером около 1,53 МБ, а не полный `prismlauncher.exe` и не исходники.

## Что делает патчер

1. Автоматически предлагает обычный путь установки Prism Launcher или
   позволяет выбрать `prismlauncher.exe` вручную.
2. Требует полностью закрыть Prism Launcher.
3. Вычисляет SHA-256 и выбирает подходящий delta-патч из встроенного каталога.
4. Неизвестный или уже изменённый EXE не трогает.
5. Сохраняет оригинал в
   `%LOCALAPPDATA%\PrismModFolders\backups\<версия>\<sha256>`.
6. Собирает новый EXE во временный файл, проверяет его SHA-256 и только после
   этого атомарно заменяет оригинал.
7. Позволяет вернуть официальный EXE кнопкой «Восстановить оригинал».

Патчер намеренно не читает и не изменяет `%APPDATA%\PrismLauncher`, где
хранятся сборки, аккаунты, настройки и игровые файлы.

## Поддержка версий

Сейчас в каталог встроена официальная Windows-сборка Prism Launcher 11.0.3:

```text
официальный SHA-256:
C24C7C84FCE7FF1D12C709E0BCC8993AAA2A8CB662381C960CCB7D93C88BC2E3

изменённый SHA-256:
083834047BCB5139C032E163EE38AC4C10529ED8BC6CC180400176E979CE5ECE
```

Сам движок не привязан к одной версии: будущая поддержка добавляется новой
записью с версией, двумя хешами и отдельной delta. Это безопаснее попытки
применять машинный патч к неизвестному бинарному файлу.

## Пересборка

Сначала сгенерировать delta из официального и изменённого EXE:

```powershell
BinaryDeltaBuilder.exe `
  official-prismlauncher.exe `
  patched-prismlauncher.exe `
  PrismModFolders-11.0.3.pmdelta
```

Затем собрать патчер:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\build-patcher.ps1 `
  -Delta .\PrismModFolders-11.0.3.pmdelta
```

Для автоматической проверки встроенной delta без изменения исходного файла:

```powershell
PrismModFoldersPatcher-11.0.3.exe `
  --self-test official-prismlauncher.exe reconstructed.exe
```

Изменённый Prism Launcher распространяется по GPL-3.0, поэтому публичный
выпуск патчера должен сопровождаться соответствующими исходниками или
доступной ссылкой на них.
